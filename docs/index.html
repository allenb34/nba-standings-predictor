How the predictions are doing

Loading the latest standings…

Pace wins = current win% × 82. MAE = mean absolute gap between predicted and pace wins, across all 30 teams. Spearman ρ compares the predicted order with the actual order inside each conference (1 = identical, 0 = unrelated). Early in the season pace wins swing a lot, so treat these numbers as noisy until roughly 20 games in.

Coach-adjusted (v2, exploratory) adds a cross-validated head-coach effect to the locked model. Validation shrank every coach's effect to almost zero, so v2 differs from the official predictions by less than 0.005 wins. It is tracked for comparison only; the locked v1 predictions are the official, scored ones. Read the coach analysis.

Data: stats.nba.com via nba_api, updated weekly. Predictions were locked at git tag v1-lock and are never edited.
