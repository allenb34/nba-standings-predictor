Conformance target

This site aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. It is partially conformant: most of the content meets the standard, with the known limitations listed below.

The site uses no accessibility overlay or plug-in. Accessibility is built into the HTML and CSS.

What we did

  • Semantic landmarks (header, navigation, main, footer) and a skip link to the main content.
  • Standings are real HTML tables with captions and row and column headers.
  • Every chart has a written summary and a data table holding the same values.
  • Color is never the only signal: teams ahead of or behind their prediction are marked with ▲/▼ and the words "ahead" or "behind", and chart markers differ by shape (diamond, circle, bar) as well as color.
  • Text contrast is at least 4.5:1 and chart graphics at least 3:1, in both light and dark color schemes.
  • Everything works with a keyboard, with a visible focus outline. Nothing relies on hover.
  • The layout reflows at 320 CSS pixels wide and at 200% zoom. Wide tables scroll sideways inside their own box, which is keyboard-focusable.
  • The site has no animation, and the reduced-motion preference is respected if any is added later.

How it was tested

  • Automated check with axe-core 4.10 on both pages: no violations.
  • Manual keyboard-only pass through every link and scrollable table.
  • Visual checks in light and dark mode, at 320 pixels wide, and at 640 pixels wide (the same layout as 200% zoom on a 1280-pixel screen).

It has not been tested with screen reader users or by an independent auditor.

Known limitations

  • The chart is hidden from screen readers, because the summary and table right next to it hold the same information in a more usable form.
  • On narrow screens the standings tables need sideways scrolling; that's the only way to keep nine columns of numbers lined up with their headers.
  • The dashboard needs JavaScript to draw the tables and chart from the weekly data file. Without JavaScript, only the explanatory text appears.
  • Linked GitHub pages are outside this site's control.

Report a problem

If something on this site doesn't work for you, please tell us by opening an issue on GitHub. Please include the page and what went wrong. We aim to reply within 5 business days.
